// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

An accented window floats at the top-center of the usable monitor area. The usable area is the workspace monitor's visible rectangle after AeroSpace outer gaps are applied. Its width and height default to two-thirds of that area, so the default frame on a 1920x1080 monitor with no outer gaps is 1280x720 at position (320, 0).

Set `accent-width-percent` and `accent-height-percent` to integer percentages from 1 through 100 to customize the dimensions. Either setting may be omitted to retain its two-thirds default:

[source,toml]
----
accent-width-percent = 75
accent-height-percent = 80
----

For an available rectangle, `area`, the configured frame is:

----
widthRatio  = accent-width-percent / 100, or 2 / 3 when omitted
heightRatio = accent-height-percent / 100, or 2 / 3 when omitted
width       = area.width * widthRatio
height      = area.height * heightRatio
x           = area.minX + (area.width - width) / 2
y           = area.minY
----

Running `accent` on a tiled or ordinary floating window makes it accented and floating. Removing a tiled window from the tiling tree causes the remaining tiled windows to rebalance normally.

Running `accent` again on an accented window clears accent mode and returns the window to tiling. An ordinary floating window therefore returns to tiling after the second toggle. The exact prior tiling position and weight are not restored.

Accent state is per-window. Multiple windows can be accented simultaneously and may overlap.

The following example binds accent mode to ctrl-alt-c:

[source,toml]
----
[mode.main.binding]
ctrl-alt-c = 'accent'
----
