= aerospace-move-workspace-to-monitor(1)
include::util/man-attributes.adoc[]
:manname: aerospace-move-workspace-to-monitor
// tag::purpose[]
:manpurpose: Move workspace to monitor targeted by relative direction, by order, or by pattern.
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace move-workspace-to-monitor [-h|--help] [--workspace <workspace>] [--swap] [--wrap-around] (left|down|up|right)
aerospace move-workspace-to-monitor [-h|--help] [--workspace <workspace>] [--swap] [--wrap-around] (next|prev)
aerospace move-workspace-to-monitor [-h|--help] [--workspace <workspace>] [--swap] [--] <monitor-pattern>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}
Focus follows the focused workspace, so the workspace stays focused.

Without `--swap`, the command fails when the moved workspace's xref:guide.adoc#assign-workspaces-to-monitors[monitor force assignment] disallows the destination.
When `--swap` performs an exchange, it validates both workspace assignments before either workspace is moved, so a disallowed assignment fails without changing either monitor.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--swap:: Exchange the moved workspace with the target monitor's active workspace instead of replacing the source monitor's workspace with an invisible stub workspace when either the target is directional (`left`, `down`, `up`, or `right`) or exactly two monitors are connected.
The workspace being moved must be visible when an exchange is performed.
For non-directional targets with any other number of monitors, this option uses the normal move behavior.
--wrap-around:: Allows to move workspace between first and last monitors

--workspace <workspace>::
include::./util/workspace-flag-desc.adoc[]

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

(left|down|up|right)::
Move workspace to monitor in direction relative to the focused monitor.
With `--swap`, directional targets exchange workspaces regardless of the number of connected monitors.

(next|prev)::
Move the workspace to next or prev monitor.
'next' or 'prev' monitor is calculated relative to the monitor `<workspace>` currently belongs to.

<monitor-pattern>::
Find the first matching monitor and move the workspace there.
Multiple monitor patterns is useful for different monitor configurations.
Monitor patterns follow the same format as in `workspace-to-monitor-force-assignment` config option

The default configuration uses a binding mode for directional workspace swaps:

[source,toml]
----
[mode.main.binding]
    alt-shift-tab = 'mode move-workspace'

[mode.move-workspace.binding]
    h = ['move-workspace-to-monitor --swap left',  'mode main']
    j = ['move-workspace-to-monitor --swap down',  'mode main']
    k = ['move-workspace-to-monitor --swap up',    'mode main']
    l = ['move-workspace-to-monitor --swap right', 'mode main']
    esc = 'mode main'
----

Press `alt-shift-tab`, release it, and then press `h`, `j`, `k`, or `l`.
After a move, the binding returns to `main` mode; `esc` cancels without moving.
Existing configuration files must update these bindings manually.

// end::body[]
